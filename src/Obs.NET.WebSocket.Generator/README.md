# OBS WebSocket Client Generator

This project generates C# client code from the OBS WebSocket protocol definition (`protocol.json`) using **Scriban templates**.

## Overview

When a new `protocol.json` file is released by OBS, run this generator to produce:

- **Enums** (7 types) - All protocol enums with proper JSON serialization and [Flags] attributes
- **Requests** (146 types) - Request and Response classes for each API call
- **Events** (57 types) - Event data classes for all OBS events
- **Extension Methods** (146 methods) - Strongly-typed extension methods for ergonomic API calls
- **Event Handlers** (57 handlers) - Strongly-typed event handler declarations for the client

All generated files are written to the `src/Obs.NET/Generated/` directory with proper `<auto-generated>` headers.

## Usage

### Run the Generator

```bash
# From the repository root
dotnet run --project src/Obs.NET.WebSocket.Generator
```

The generator will:

1. Load `protocol.json` from the resources directory
2. Parse the OBS WebSocket API definition
3. Generate all C# files using Scriban templates
4. Write files to `src/Obs.NET/Generated/`

### Output Structure

All generated files are placed in `src/Obs.NET/Generated/`:


## Architecture

### Resources Directory

Located in `resources/`:

- **protocol.json** - OBS WebSocket protocol definition (from obs-websocket repo)
- **ObsWsEnumTemplate.txt** - Generates enum types with [Flags] support
- **ObsWsRequestTemplate.txt** - Generates Request and Response classes
- **ObsWsEventTemplate.txt** - Generates Event data classes
- **ObsWsExtensionMethodsTemplate.txt** - Generates extension methods for ObsWsClient
- **ObsWsEventHandlersTemplate.txt** - Generates event handler declarations and dispatcher

### Generators

Located in `Generators/`:

- **EnumGenerator.cs** - Generates enum types from protocol enums
- **RequestGenerator.cs** - Generates Request and Response classes
- **EventGenerator.cs** - Generates Event data classes
- **ExtensionMethodsGenerator.cs** - Generates strongly-typed extension methods
- **EventHandlerGenerator.cs** - Generates event handler declarations and dispatcher

### Utilities

Located in `Utilities/`:

- **TypeMapper.cs** - Maps OBS types to C# CLR types
- **NamingHelper.cs** - Handles naming conventions and identifier sanitization

### Models

Located in `Models/`:

- **ObsWsApiDefinition.cs** - Root container for the entire API definition
- **ObsWsRequest.cs** - Request definition with request/response fields
- **ObsWsEvent.cs** - Event definition with event data fields
- **ObsWsEnum.cs** - Enum definition with identifiers

## Updating Protocol

When OBS releases a new protocol:

1. **Download** the new `protocol.json` from the [obs-websocket protocol repo](https://github.com/obsproject/obs-websocket/blob/master/docs/generated/protocol.json)

2. **Replace** `src/Obs.NET.WebSocket.Generator/resources/protocol.json` with the new file

3. **Run** the generator:
   ```bash
   dotnet run --project src/Obs.NET.WebSocket.Generator
   ```

4. **Build** the Obs.NET project to verify compilation:
   ```bash
   dotnet build src/Obs.NET
   ```

5. **Test** with the examples:
   ```bash
   dotnet run --project src/Obs.NET.Example -- --example simple
   ```

6. **Commit** the updated files to version control
